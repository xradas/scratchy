# Eyesore / The Pale Ward — connected playable level with death gore

The selected corrupted-biotech concept is now an actual walkable 3D level. Containment tanks, dirty pale panels, infestation, a grated aisle, twelve broad physical stairs and the raised rear door follow the approved screenshot. The Bio Wing branches to an Operating Room key, a return shortcut, an elevated Rear Lab, a passenger lift and the discharge exit. A west service alcove is optional. Earlier projects, concepts and packages remain preserved.

Run the new standalone Linux package from `/home/rikki/Builds/eyesore-pale-ward-gore-2026-10-09/eyesore-pale-ward-gore.x86_64`. Controls: WASD, mouse, left click, 1 pistol / 2 shotgun / 3 melee, E use, Tab visited-area map, Escape pause. Settings persist. Retry recreates the entire level and audio owner. Abelian plays on the title; Bestial Paragon Interface plays in the level.

Flesh hits spray blood; armor throws sparks. Death leaves a persistent blood pool and corpse. Heavy shotgun overkill scatters nine painted creature parts; smaller deaths leave scraps beside the intact corpse. Blood samples actual physics surfaces, splitting at stair risers. Gore freezes during pause and clears on retry. The current dry hurt/death audio and music remain unchanged.

Source uses Godot **4.7.2 stable**, GDScript, Compatibility rendering and matching Linux export templates. `tools/godot.sh` verifies the pinned editor. The world renders at 640×360 with nearest scaling; HUD/menu text uses window resolution.
