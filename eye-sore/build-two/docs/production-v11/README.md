All36 actors, existing arena counts, progression geometry and eight other campaign maps are retained. New pickup ambush waves and stronger gibbing remain later cards.

Scientists use a physically blocked committed lunge. Guards fire two separately owned projectiles; pain and death cancel pending releases.
