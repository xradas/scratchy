# Shotgun security troop art

The built-in `image_gen` tool produced two transparent PNG edits using the existing security atlas and frontal attack strip as visual references. The shotgun troop retains the gritty painted pixel style, with olive fabric, ochre shoulder bands, visible red shell loops, and a longer pump shotgun. Existing pistol security art is unchanged.

- `assets/enemies/staff-v21/infected_security_shotgun-atlas.png`: native 1254 × 1254 pixels, eight directional rows and eight state columns.
- `assets/enemies/staff-v21/infected_security_shotgun-front-attack.png`: native 1774 × 887 pixels, two 887 × 887 frontal windup/release cells.

Both PNGs retain generated bytes without resizing, repainting, padding, masking, or alpha edits. `assets/combat_art.json` registers native integer source rectangles and measured foot pivots, matching the existing movement and state clip contract. Per-row column boundaries avoid all opaque pixels. The front overrides retain matching world scale, foot alignment, and centered muzzle positions. The gore profile samples the new olive troop atlas rather than the pistol sprite.

The prompt set requested the original grid, views, poses, infected anatomy, and pixel style, replacing the compact weapon with a pump shotgun and changing only the troop identifiers described above. Detailed registration, hashes, source paths, prompt set, and verification are in `docs/production-v21/shotgun-staff-art.json`.

Verification: Godot 4.7.2 imported both assets successfully. A focused runtime check passed 22 assertions covering the walk cycle, frontal pose overrides, muzzle alignment, directional fallback, and troop gore texture. Existing combat-art data and pistol PNG bytes were checked unchanged.

Review caveat: source art and runtime pose registration were inspected; oblique firing poses remain approximate, as with the original staff atlas. This is not a complete in-level animation or gameplay acceptance review.
