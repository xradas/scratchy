# Visual asset provenance

The Pale Ward concept board and current transparent creature/weapon sprite adaptations were produced with the built-in imagegen tool for this project. They are generated art, not hand-authored pixel animation. The original approved board is retained unchanged under concepts/visual-v2/corrupted-biotech; current exact edit prompts, generated originals, hashes and runtime registration are under concepts/sprite-art-v1. Runtime title uses the approved scene unchanged, with its concept HUD cropped by a Godot AtlasTexture region.

Original environment textures/geometry, muzzle-effect pixels, scripts and the preserved procedural mesh studies were authored for this project. No original Doom/Quake game graphics, models or textures were copied. The concept reference audit is recorded in docs/DOOM_VISUAL_AUDIT.md. Audio creators/licenses are credited separately in audio/CREDITS.md.

The current ceramic, steel and grate materials sample the original approved concept board directly. assets/materials/pale-ward-approved-board.png is a byte-identical copy; assets/materials/approved-material-regions.json records the exact source rectangles and hashes. Native region-local nearest sampling preserves the selected source pixels without cropping, resampling or new image generation. Floor plates use the approved steel sample. Geometry, lighting, repetition and shader relief affect the rendered appearance; exact source pixels do not establish whole-scene visual acceptance.

Earlier reference-based environment textures and the current infestation cutout were generated with built-in imagegen from the approved Pale Ward scene. Exact prompts/output paths are in concepts/environment-art-v1; PNG bytes remain unchanged. The earlier texture variants and procedural rooms are preserved.

Blood-pool and torn-creature-remains atlases are original built-in imagegen outputs, referenced to the approved Pale Ward scene. Exact prompts, original output locations, byte hashes and transparency audit are retained in concepts/gore-art-v1. PNGs are unchanged. Runtime uses only pool cells0/1 (the unused lower cells clip their source borders), and all eight remains cells. Native mesh UVs select atlas cells; shared world collision queries conform stains/remains to solid surfaces and split across risers. Creature pieces retain the source painted shading, dimmed to match the ward. These are generated raster assets, not hand-authored sprites.
