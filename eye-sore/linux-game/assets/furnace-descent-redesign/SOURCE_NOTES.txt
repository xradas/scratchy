METHOD / PROVENANCE
Inspected actual existing assets/infernal-wall.bmp, infernal-floor.bmp and infernal-ceiling.bmp via PNG review conversion; those assets are untouched. Generated six independent new material rasters with built-in image_gen. Wall/floor used existing material images as color/construction references; none used another game's texture or screenshot. Prompts preserved verbatim in GENERATION_PROMPTS.txt. Generated 1254 square source masters in source/ retained. All prior material sets, including Starling and White Hunger, preserved.
Masters exported to 1024 square RGB PNG by nearest resizing. Runtime files 256 square opaque 24-bit BMP3. Edge-phase crops for four seamfit exports use small boundary removals (at most23 source pixels on any edge) to align image boundaries with natural periodic construction phases; exact crop recorded in export-crop-inspection.json. Initial exports retained alongside seamfit exports.

PALETTE / CONSTRUCTION
Shared muted charcoal basalt/iron, ash gray, rust umber, red/orange ember, sparse yellow-orange molten core. Wall is large irregular rock planes and selective braces; ash floor has quiet support faces; industrial floor has plate assembly; ceiling uses repeated exhaust structure; elevation uses clear transverse rib rhythm; lava omits mechanical grid entirely.
Requested palette anchors: charcoal #343230, ash #60594f/#777064, rust #77472c, ember #d94b12, rare core #f29935/#ffc154. Generated colors are approximate, not exact indexed palette values. Measured means in candidate-surface-inspection.json; no claim of enforced32-color palette.
Primary floor ash is lighter/quieter than wall and industrial floor, improving role separation in the artwork; in-game readability remains unassessed.

REPEAT / GEOMETRY GUIDANCE
Current native renderer: linear minification, nearest magnification, repeat wrap, no mip levels. Standard room floor maps one tile per2world units; outer walls have horizontal2unit repeat but vertical1.25unit repeat, internal walls horizontal1unit, vertical1.25unit. Current pillar1.14width/4.55height maps1x4, different from floors. These inconsistent densities will still distort material regardless of source quality.
Recommended uniform physical repeat: wall tile2x2world units (four courses -> .5unit high); ash and iron floor tile2x2units; ceiling tile2x2units. Preserve common texel density128source pixels perworld unit for256runtime.
Elevation texture: map entire tile over four real treads or .8–1.2units depth so each .2–.3unit rise/landing pattern reads at roughly intended scale; rotate ribs transverse to travel. Riser should receive assigned construction material, never texture stairs painted on a flat collider.
Lava repeat2–3world units and apply only to explicit nonwalkable/damaging regions; worn iron ember accents remain nonhazardous decoration.
Real elevation/stairs require actual geometry/collision support; current camera height is fixed in standard mode. Textures do not add vertical gameplay.
Sampler may shimmer on slanting floor; no moving renderer/game test by this specialist. Use restrained mip/filter work after candidate choice.
Wall/floor still intentionally resemble the current infernal construction family; the expanded differences are material roles, ash floor, clearer tread and lava, quieter ceiling and coarser wall arrangement. No new setting inferred.
No engine/source/build scripts modified. No current files overwritten. Review these replacements before runtime integration.
