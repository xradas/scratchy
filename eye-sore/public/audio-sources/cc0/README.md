# CC0 foley sampler

`metal1.wav`, `steel1.wav`, and `cracker2.wav` are imported from [code4fukui/sound-cc0](https://github.com/code4fukui/sound-cc0). The upstream project dedicates them to the public domain under CC0/Unlicense; its verbatim license is retained in `LICENSE`.

They are used as source foley in the industrial music bed and enemy hit-effects build scripts. Derived runtime WAV files are 44.1 kHz mono PCM.
