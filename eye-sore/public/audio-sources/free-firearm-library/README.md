# Recorded firearm sampler

The PPQ pistol, Mossberg shotgun, and AK-47 recordings here are selected field
recording takes from [The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library), supplied through the [FPS Asset Kit](https://github.com/petroulacl/fps-asset-kit). Both sources identify the recordings as CC0/public domain. Three distinct takes are retained for each weapon so the game can rotate the audible shot rather than repeating one sampled WAV; the small `cc0` foley sampler only adds mechanical impact texture.
