# Contributing

## Before making changes

Read `AGENTS.md`, `docs/architecture.md` and the documentation relevant to the component being changed.

## Development rules

- Keep UI and patch-engine responsibilities separate.
- Add tests for new engine behaviour.
- Update documentation with architectural or compatibility changes.
- Do not commit third-party APKs, extracted proprietary files, credentials or signing material.
- Run the build and relevant tests before submitting substantial changes.

## Commits

Use concise, descriptive commit messages and keep unrelated changes in separate commits where practical.
